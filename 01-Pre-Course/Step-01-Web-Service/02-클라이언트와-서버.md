## 웹 서비스 이해 2강 - 클라이언트와 서버

### 1. 오늘 배운 핵심 개념

**① 웹 서비스의 기본 흐름**
- URL 입력 → DNS 조회 → HTTP/HTTPS 요청 → 서버 처리 → 응답 반환 → 브라우저 렌더링

**② 서버의 종류와 역할**
- **웹 서버(Web Server)**: HTML, CSS, JS, 이미지 등 정적 리소스를 제공
- **WAS(Web Application Server)**: 사용자 요청에 따라 동적인 데이터 처리
- **DB(Database)**: 데이터 저장, 조회, 수정, 삭제

**③ 데이터베이스 접근 기술**
- **ORM**: 객체와 관계형 데이터베이스를 매핑하는 기술
- **JPA**: 자바의 ORM 표준 인터페이스
- **MyBatis**: SQL을 직접 작성하고 결과를 객체에 매핑하는 기술

### 2. 새롭게 알게 된 점

웹 서버와 WAS의 역할 차이를 이해하고, 사용자 요청이 서버와 데이터베이스를 거쳐 화면에 표시되기까지의 흐름을 배웠다. 특히 JPA와 MyBatis처럼 데이터베이스에 접근하는 방식에도 차이가 있다는 점을 알게 되었다.
